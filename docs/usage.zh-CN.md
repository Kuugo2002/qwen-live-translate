# 俄语实时翻译助手

适用于 Windows 10 / 11 64 位。使用 Qwen3.8-LiveTranslate-Flash-Realtime，将所选播放设备的声音实时翻译为中文字幕。

## 开始使用

1. 打开发布文件夹里的「俄语实时翻译助手.exe」。
2. 选择声音来源。电脑声音从哪个耳机或扬声器播放，就选择哪个设备。
3. 填写自己的千问 API 密钥。首次开始翻译时会在本机加密保存，以后打开会自动读取。
4. 点击「开始翻译」，在浏览器、播放器或会议软件中播放俄语声音。
5. 中文逐步显示在主窗口；点击「悬浮字幕」显示可拖动、置顶的字幕窗口，A− / A+ 调整字号。
6. 点击「停止」等待最后一段完成，可通过「导出记录」保存中文与原文。

默认源语种自动识别，目标语种固定为中文。模型也可能翻译听到的其他语言。原文和译文由服务端分段返回，时间与实际音频可能略有差异。

## 接口和数据

- 默认接口：`wss://maas.qianwenaiapi.com/api-ws/v1/realtime`，已用指定模型完成真实俄语音频翻译测试。
- 如果使用其他地域或业务空间，请在「接口设置」中填写对应的 WebSocket 地址。程序自动添加指定模型参数，密钥必须属于对应服务。
- 开始翻译后，所选设备的全部播放声音会发送到千问云端。默认仅请求文字输出。
- API 密钥保存在 `%LOCALAPPDATA%\QwenLiveTranslate\secret.bin`，使用 Windows 当前账户加密。设置与密钥均不包含在发布文件中，也不会写入导出的字幕。
- 停止后不会继续采集或上传声音。字幕只保存在本次程序内存中，关闭前请导出需要的记录。

## 常见问题

- **没有字幕**：检查音量条是否变化，确认所选设备和播放器的输出一致；换设备后停止并重新选择。沉默、纯音乐不会产生正常语音字幕。
- **网络或鉴权错误**：检查网络、密钥、接口地域，以及账户是否有模型调用权限和可用余额。
- **字幕延迟**：取决于网络、语速和模型分段，无法保证零延迟。断线会停止并显示原因，请点击「开始翻译」重连。
- **独占模式或受保护内容**：某些程序的声音可能无法通过系统回环采集；尝试关闭播放器独占模式。
- **全屏字幕**：普通置顶窗口可能无法覆盖独占全屏程序；可将播放器切为无边框或窗口模式。

## 开发与构建

源码位于 `QwenLiveTranslate`，使用 .NET 10 WPF、NAudio 2.2.1、ClientWebSocket。

安装 .NET 10 SDK 后，在本项目目录运行 `./build.ps1 -Portable`，生成无需另装 .NET 的 Windows x64 便携版。

开发诊断：程序参数 `--self-test` 验证字幕合并和音频采集；`--probe --wav <音频路径>` 使用本机密钥执行真实接口测试；追加 `--loopback` 则实际播放测试音频并回环采集上传。接口测试会产生模型调用费用。测试结果写入运行目录的 `test-results` 文件夹。
